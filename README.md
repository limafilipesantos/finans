# Finans

Projeto de estudo de uma página responsiva de finanças pessoais, desenvolvido com HTML, Bootstrap 5 e Bootstrap Icons.

## Visualizar

Abra `index.html` no navegador. Os ícones do Bootstrap Icons são carregados pela internet.

## Estrutura

- `index.html`: página principal.
- `css/`: estilos do Bootstrap.
- `js/`: scripts do Bootstrap.
- `img/`: imagens PNG do projeto.

## Estado atual

O projeto é uma interface estática. O formulário de cadastro ainda não envia dados. Os links para `recursos.html`, `beneficios.html`, `precos.html` e `login.html` apontam para páginas que ainda não estão incluídas. Os links das redes sociais são exemplos.

## GitHub Pages

Após enviar os arquivos para o repositório, selecione Settings > Pages > Deploy from a branch, escolha a branch principal e a pasta / (root), e salve. O arquivo `index.html` deve ficar na raiz do repositório.
